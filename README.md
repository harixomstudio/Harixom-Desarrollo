# Harixom

Harixom es una plataforma web desarrollada para la gestión y administración de información mediante una arquitectura moderna basada en TypeScript y PHP.

## Tecnologías utilizadas

- TypeScript
- PHP
- Laravel
- Blade
- JavaScript
- HTML
- CSS
- Docker

## Características

- Gestión de usuarios
- Interfaz web responsiva
- Backend API desarrollado en TypeScript
- Integración con base de datos
- Arquitectura escalable
- Contenedorización con Docker

## Estructura del proyecto

```text
harixom/
├── backend/
├── frontend/
├── resources/
├── routes/
├── database/
├── docker/
└── README.md
```
## Requisitos
- Node.js 18+
- PHP 8+
- Composer
- Docker (opcional)
- MySQL o PostgreSQL
  
## Instalación
- Clonar el repositorio
- git clone https://github.com/usuario/harixom.git
- cd harixom
- Backend
- npm install
- npm run dev
- Laravel
- composer install
- cp .env.example .env
- php artisan key:generate
- php artisan migrate
- php artisan serve

## Variables de entorno

- Configura las variables necesarias en el archivo .env antes de iniciar la aplicación.
